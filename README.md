# FolderNode releases

Official macOS downloads and signed update files for [FolderNode](https://foldernode.app).

This repository contains distribution assets only. FolderNode application source code is maintained separately in a private repository.

## Downloads

See [Releases](https://github.com/KentaroKoga/foldernode-releases/releases) for available versions. Download the macOS ZIP for manual installation. Update archives, signatures and `latest.json` are used by the in-app updater.

## Help and feedback

Start with the [setup and troubleshooting guide](https://foldernode.app/docs/troubleshooting/). For bug reports and feature requests, use **Settings → Feedback** in the app.
